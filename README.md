# 🌍 Winarti | GIS Specialist Portfolio

A premium, responsive, and intriguing portfolio website designed for a GIS Specialist & Spatial Data Analyst. This project features a calm pastel aesthetic, dark mode support, and a dedicated 1-page printable resume.

---

## 🚀 Tutorial: How to Publish to GitHub Pages

Follow these steps to get your portfolio live on your own `github.io` domain.

### Step 1: Create a GitHub Repository
1.  Log in to your [GitHub account](https://github.com/).
2.  Click the **+** icon in the top right and select **New repository**.
3.  **Repository name**: Use something like `portfolio` or `winarti-gis`.
4.  Set it to **Public**.
5.  Click **Create repository**.

### Step 2: Upload Your Files
You can upload the files directly through the browser:
1.  In your new repository, click the **uploading an existing file** link.
2.  Drag and drop **all** the following from your computer into the browser:
    - `index.html` (The main website)
    - `resume.html` (The printable CV)
    - `static/` (Folder containing CSS and JS)
    - `assets/` (Folder containing the background image)
3.  Wait for the upload to finish, type a commit message like "Initial portfolio launch", and click **Commit changes**.

### Step 3: Enable GitHub Pages
1.  Go to the **Settings** tab at the top of your repository.
2.  On the left sidebar, click **Pages**.
3.  Under **Build and deployment** > **Branch**:
    - Select **main** (or master).
    - Ensure the folder is set to **/(root)**.
    - Click **Save**.

### Step 4: Access Your Website
Wait about 1–2 minutes. Your site will be live at:
`https://yourusername.github.io/your-repository-name/`

## 🛠️ Project Structure
-   `index.html`: The main interactive portfolio with the Bento grid and animations.
-   `resume.html`: A clean, tidy, 1-page version of your CV for printing.
-   `static/css/style.css`: The "Intriguing" design system and dark mode logic.
-   `static/css/resume.css`: Print-optimized styles for the CV.
-   `static/js/script.js`: Handle smooth scrolling, dark mode toggle, and mobile menu.
-   `assets/`: Contains the topographic background image.

---

## 🎨 Customization
-   **Colors**: Open `static/css/style.css` and modify the `:root` variables to change the pastel theme.
-   **Content**: Edit the text directly inside `index.html` and `resume.html`.
